# Spotlight

A black screen with a white circle you can drag around, for use as a spotlight.

Live at https://pineapplesaul.github.io/spotlight/

## Controls

- Drag (mouse or touch) to move; arrow keys nudge (Shift for bigger steps)
- Scroll, pinch or `+` / `-` to resize
- `1`-`9` pick a colour, `C` cycles colours
- `S` toggles a soft edge
- `F` or double-click for fullscreen, `H` shows or hides the controls hint (it also hides as soon as you click)
